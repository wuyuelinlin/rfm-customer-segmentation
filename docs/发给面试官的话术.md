## 场景三：面试现场口头介绍（30 秒）

```
我做过一个电商用户价值分层的项目。用 1000 名用户的交易和行为数据，在 RFM 基础上加了互动度和忠诚度两个维度，把用户分成 15 类，再针对不同人群设计营销策略、测算 ROI。

结果是传统 RFM 策略 ROI 只有 4%，我的分层策略做到 33.5%，成本还少花了 410 块。我还做了敏感性分析，证明这个结论在转化率 15% 以上都成立。

项目代码和结果我放在 GitHub 上，可以给您看。
```

## 发送前检查清单

- [ ] 把 `【你的GitHub用户名】` 替换成真实用户名

- [ ] 简历 PDF 用真实姓名命名（王耀辉-个人简历.pdf）
- [ ] 邮件附件不超过 10MB（当前 PDF 约 320KB，没问题）

## 简历里怎么放这个链接

在简历「基本信息」区加一行：

```
GitHub：github.com【你的GitHub用户名】
```

或者在「职业技能」区末尾加一行：

```
项目作品：github.com【你的GitHub用户名】/rfm-customer-segmentation
```

**建议两个都放**——基本信息放主页，技能区放项目直达链接，HR 扫到哪都能点进去。
