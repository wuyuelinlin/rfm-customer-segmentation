# 电商用户价值分层与精准营销策略分析

> 基于 RFM-I 改进模型的用户分群与营销 ROI 测算 · R 语言完整分析项目

一套从**数据审计 → 特征工程 → 用户分层 → 策略模拟 → 可视化交付**的完整数据分析流程。在经典 RFM 模型基础上引入互动度（I）与忠诚度（L）维度，将 1000 名用户划分为 15 类价值群体，并量化对比两种营销策略的投入产出。

---

## 核心结论

| 策略 | 目标用户 | 成本 | 边际 ROI |
|---|---|---|---|
| 传统 RFM Top20 | 200 人 | 2,000 元 | **4.0%** |
| 优化 RFI 分层 | 159 人 | 1,590 元 | **33.5%** |

**优化策略少花 410 元，ROI 提升 8.3 倍。**

关键洞察：传统 RFM 选的是"本来就会买"的高分用户，发券的增量有限；分层策略瞄准"纠结土豪"与"高潜沉睡用户"等对优惠边际响应更大的群体，把预算花在刀刃上。

**稳健性**：对转化率假设做 5%–30% 全区间扫描，潜力用户转化率 ≥15% 时优化策略始终优于传统策略，结论不依赖单一假设。

## 分析方法

### 1. 数据质量审计
- 检查缺失值、重复 ID、年龄异常值
- **发现伪特征**：原始 `Interests` 与 `Product_Category_Preference` 取值域完全不同（Sports vs Books），直接相等匹配恒为 0；经卡方检验确认两字段独立，改用业务语义映射修复

### 2. 特征工程
- 互动度 I = 标准化浏览时长 × 0.5 + 标准化浏览页数 × 0.5
- 阻力系数 Friction = 浏览页数 / (购买频次 + 1)
- 忠诚度 L：订阅且 7 天内登录 = 3，未订阅但 7 天内登录 = 2，其余 = 1
- 收入分层：按 33%/66% 分位数切为低/中/高三组

### 3. RFM-I 综合评分
```
RFM = 0.2×R + 0.3×F + 0.5×M
I 权重 = I_Score / 100 × 0.2
Final_Score = RFM × (1 + I 权重)
```
权重依据：消费金额（M）最直接影响收入，频次（F）体现粘性，最近登录（R）在本数据集中信号偏弱。

### 4. 用户分层
基础 RFM 八分类 + 7 类业务修正规则 → 15 类价值群体（核心VIP、纠结土豪、高潜沉睡用户等）。

**分层验证**：k-means 轮廓系数最高 0.223（k=8），说明数据本身无强天然簇，最终采用业务可解释的规则分层——牺牲部分统计"自然度"，换取每一类都能直接对应运营动作。

### 5. 策略模拟
- 方案 A：传统 RFM Top20，按 RFM 得分前 20% 选人
- 方案 B：优化 RFI，80% 预算投核心用户、20% 投高边际响应的潜力用户
- 边际 ROI =（发券增量收入 − 券成本）/ 券成本

## 数据来源与说明

数据集为电商用户个性化特征公开数据集，含 1000 名用户的 14 个字段（年龄、性别、收入、兴趣、最近登录、购买频次、客单价、消费总额、浏览时长、浏览页数、品类偏好等）。

本项目为**个人数据分析练习项目**，用于展示完整分析流程与方法论，非真实商业项目。策略 ROI 为基于假设转化率的模拟测算，非真实投放结果。
